About Me

I'm an undergraduate Computer Engineering major at UC Santa Barbara (from the Bay Area), interested in Hardware, Robotics, and Machine Learning research. Whether it's tinkering with robotics or researching edge devices: I'm always driven to explore and build greater.

This summer, I've been researching neuro-inspired computer architecture for energy efficient bionic vision applications. This entailed building truly sparse, event-based representations for real-time, low-power retinal prosthesis stimulation on edge hardware like the NVIDIA Jetson Orin Nano.

Outside of research, I've built physical systems to demonstrate my passions for the tangible interface between hardware, AI, and real-world application. Case in point, building a on-person prototype for a bionic vision processing system as well as fully designing, modeling, and building an award-winning robotic arm from scratch.
